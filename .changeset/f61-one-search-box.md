The one search box (F61). Under your library hits, the Ask bar now lists songs and albums from the catalogue (MusicBrainz and Deezer, with art and a 30-second preview). Tap one to add it: the row says it is on its way, then Ready, and the song is playable at once. A song already on the server is added straight away with nothing fetched. Enter opens the search page with the full catalogue search. The hub finds the song on Soulseek (cleaned queries, deterministic ranking, a model tie-break only when turned on), downloads it, imports it into Lidarr track by track, scans the library and pushes Ready; you never see Lidarr or slskd. Strings in English and Gujarati.
