# Mobile screenshots (feature lane Q29)

Taken in the iOS Simulator (iPhone 18 Pro, iOS 27) from a development build (`npx expo run:ios`),
signed in to the demo Jellyfin (four Kevin MacLeod tracks in one album without a cover, so the
placeholder art stands in). Light theme and English unless the name says otherwise. Scaled to half
the device resolution.
